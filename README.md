## 📌 1. Project Overview

This project is a RESTful backend API for a **Car Rental & Vehicle Fleet Management System** built with Node.js, Express, and Supabase (PostgreSQL & Supabase Auth).

### Key Features:
- **Relational PostgreSQL Schema**: Foreign keys, check constraints, and timestamps managed in Supabase.
- **Supabase Authentication**: User registration, login, and JWT Bearer token authentication middleware.
- **Date Collision Prevention**: Date-range collision validation to prevent double-booking vehicles.
- **Automated Billing Calculation**: Server-side calculation of total rental days and billing (`days * daily_rate`).
- **Fleet Availability Lifecycle**: Status transitions (`available` ➔ `rented` ➔ `maintenance` / `completed`).
- **Relational Joins**: Vehicle details with full rental history.

## 🗄️ 3. Database Schema (PostgreSQL / Supabase)

Execute this script in your **Supabase SQL Editor**:

```sql
-- 1. Vehicles Table
CREATE TABLE IF NOT EXISTS vehicles (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    brand TEXT NOT NULL,
    model TEXT NOT NULL,
    year INT NOT NULL,
    category TEXT NOT NULL CHECK (category IN ('Sedan', 'SUV', 'Luxury', 'Hatchback', 'Electric')),
    daily_rate NUMERIC(10, 2) NOT NULL CHECK (daily_rate > 0),
    fuel_type TEXT NOT NULL,
    seating_capacity INT NOT NULL DEFAULT 5,
    status TEXT NOT NULL DEFAULT 'available' CHECK (status IN ('available', 'rented', 'maintenance')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Rentals / Bookings Table
CREATE TABLE IF NOT EXISTS rentals (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id UUID NOT NULL, -- references Supabase auth.users
    vehicle_id BIGINT REFERENCES vehicles(id) ON DELETE RESTRICT,
    customer_name TEXT NOT NULL,
    customer_email TEXT NOT NULL,
    start_date DATE NOT NULL,
    end_date DATE NOT NULL,
    total_cost NUMERIC(10, 2) NOT NULL,
    status TEXT NOT NULL DEFAULT 'booked' CHECK (status IN ('booked', 'active', 'completed', 'cancelled')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    CONSTRAINT valid_date_range CHECK (end_date >= start_date)
);
```

## 📋 5. API Endpoints

### 🔐 Authentication

| Method | Endpoint | Description | Request Body Example | Status Codes |
|---|---|---|---|---|
| `POST` | `/api/auth/register` | Register new customer | `{"email":"driver@travel.com","password":"mypassword123","name":"David"}` | `201 Created`, `400 Bad Request` |
| `POST` | `/api/auth/login` | Login and get access token | `{"email":"driver@travel.com","password":"mypassword123"}` | `200 OK`, `401 Unauthorized` |

### 🚗 Vehicle Fleet Management

| Method | Endpoint | Auth Required | Description | Request Body Example | Status Codes |
|---|---|:---:|---|---|---|
| `GET` | `/api/vehicles` | No | Fetch all vehicles (supports `?category=SUV&status=available`) | None | `200 OK` |
| `GET` | `/api/vehicles/:id` | No | Get vehicle details with past rental records | None | `200 OK`, `404 Not Found` |
| `POST` | `/api/vehicles` | Yes | Add new vehicle to fleet | `{"brand":"Tesla","model":"Model 3","year":2024,"category":"Electric","daily_rate":4500,"fuel_type":"EV","seating_capacity":5}` | `201 Created`, `400 Bad Request` |
| `PUT` | `/api/vehicles/:id` | Yes | Update vehicle daily rate or status | `{"daily_rate":4800,"status":"maintenance"}` | `200 OK`, `404 Not Found` |
| `DELETE` | `/api/vehicles/:id` | Yes | Delete vehicle from fleet | None | `200 OK`, `400 Has Active Bookings` |

### 📅 Rental & Booking Operations

| Method | Endpoint | Auth Required | Description | Request Body Example | Status Codes |
|---|---|:---:|---|---|---|
| `POST` | `/api/rentals` | Yes | Book vehicle (Date collision check & billing calculation) | `{"vehicle_id":1,"start_date":"2026-05-01","end_date":"2026-05-05","customer_name":"David","customer_email":"david@test.com"}` | `201 Created`, `400 Collision/Error` |
| `GET` | `/api/rentals/my-bookings` | Yes | List rentals for authenticated user | None | `200 OK` |
| `PATCH` | `/api/rentals/:id/cancel` | Yes | Cancel upcoming rental | None | `200 OK`, `400 Cannot Cancel` |
| `PATCH` | `/api/rentals/:id/complete` | Yes | Mark car as returned (Sets vehicle status back to `available`) | None | `200 OK` |

## 🧪 6. Testing & Validation

### Date Collision Test:
1. Register and Login to receive a JWT Bearer token.
2. Book Vehicle #1 for dates `2026-05-01` to `2026-05-05`. (Expected: `201 Created`)
3. Attempt to book Vehicle #1 for dates `2026-05-03` to `2026-05-07`.
4. The server validates overlapping intervals and rejects the request with:
   ```json
   {
     "message": "Vehicle already reserved during this timeframe."
   }
   ```
   (Expected: `400 Bad Request`)
